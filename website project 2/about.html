About Student Portal

A learning project designed to bring together common HTML page structures in one small website.

Our purpose

This website is a front-end practice project. It demonstrates how multiple HTML pages can share a consistent navigation menu, visual style, and useful page metadata.

What you can explore

  • Semantic page structure with header, navigation, main, section, and footer elements.
  • Forms using labels, text fields, email fields, date inputs, radio buttons, and checkboxes.
  • Shared styling through one external CSS file.
  • Internal links that connect the four pages.

Note: This is a demonstration website. It does not provide real admissions or store form submissions.
